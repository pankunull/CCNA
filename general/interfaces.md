# Interfaces

## Create/select

```
Cisco(config)#int <interface-id>
```

## Range

```
Cisco(config)#int range <int-id-start> - <int-id-end>
Cisco(config)#int range <int-id-one> , <int-id-four> - <int-id-six>
```

## Shutdown

Disable interface

```
Cisco(config-if)#shutdown
```

## No shutdown

Enable interface

```
Cisco(config-if)#no shutdown
```
